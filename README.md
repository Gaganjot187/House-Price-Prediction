# HOUSE PRICE PREDICTION 

# About the Project

This project predicts house prices using machine learning techniques in python. It uses houses property features to estimate house prices.

## Technologies Used
1. Python
2. Pandas
3. Matplotlib
4. Scikit-learn
5. Tkinter
   
# Project Files
House_prediction.ipynb - Jupyter notebook containing the code
Housing_data.csv - Dataset for training and testing
